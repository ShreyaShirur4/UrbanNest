\# UrbanNest – House Rental Management System



\## About the Project

UrbanNest is a web-based house rental management system designed to connect property owners and users. It provides functionality for managing property listings, user accounts, house details, and payments.



\## Features



\- User registration and login

\- Property listing and management

\- Add and update house details

\- House image registration

\- Admin management of users and properties

\- House deletion by owners and administrators

\- Payment management

\- Report house functionality



\## Technologies Used



\- \*\*Programming Language:\*\* Java

\- \*\*Backend:\*\* Java Servlets, JSP

\- \*\*Frontend:\*\* HTML, CSS, JavaScript

\- \*\*Database:\*\* PostgreSQL

\- \*\*Development Environment:\*\* Eclipse IDE

\- \*\*Version Control:\*\* Git and GitHub
